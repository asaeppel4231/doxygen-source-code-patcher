# Doxygen Source Code Patcher

## Disclaimer

All of the code (except for the example code of this file) of this project is generated by AI.

## About

This project fixes some bugs in the doxygen core on parsing C code by patching the source code.

## Technical Details

The doxygen source code patcher uses python's regular expressions to find the problem making macros and patch they.
The patched macro has no content (default) or optionally a link to the real macro content (for doxygen's "view file")

## Example of the bugs

Here is a minimal example which is completely irritating doxygen:

```c
#define CHECK_NULL_PARAM(param_name, no) \
do{ \
    if((param_name) == NULL){ \
        fprintf(stream, LIB_NAME ": " IN_FUNC ERROR WH_HDL_SC "INVALID_POINTER_PARAM_%d: %s is null\n", __func__, no, #param_name); \
        break; \
    } \
}while(0)
```
(citate from https://code.asaeppel.dev/asaeppel4231/lib-brlyt-reader/src/branch/master/src/errors/errors.c#L43)

If you document this code using doxygen tags (like @param), the documented things will not appear or appear in the next defined macro, etc.

## Workaround by code patching

The patched macro of the example above looks like that:

```c
#define CHECK_NULL_PARAM(param_name, no) /* View complete macro content at: https://code.asaeppel.dev/asaeppel4231/lib-brlyt-reader/src/branch/master/src/errors/errors.c#L143 */
```

Note that the comments before the macro were not affected.

# Usage example

```sh
python3 patch_code_4_doxg.py --input errors.c
```

This example would search the errors.c file relative to the current working directory, create a .tmp directory and create the patched errors.c in it.

Possible arguments:

- --input: Path to the file or directory that should be patched (if it's an directory, ALL .c and .h source files were patched!)
- --ci: Modifies the file directly instead of creating a .tmp directory
- --output: Alternative output file name (if only one file as input; otherwise output directory name)
- --remote-repository-path: Path to the remote repository (used for generating the comments in the macros if set)
